# Fortune Teller

A simple JavaScript program that randomly selects a fortune from five possible messages and displays the result in the console.

This is one of my beginner JavaScript projects, built as part of my journey toward becoming a full-stack web developer.

# What I Learned

This project helped me practice some fundamental JavaScript concepts:

- Variables using let and const
- Strings and numbers
- Math.random()
- Math.floor()
- if, else if, and else
- Comparison operators (===)
- Variable assignment
- Console output

# Technologies

- JavaScript

# How It Works

The program generates a random number between 1 and 5.

That number is then checked using conditional statements, and the corresponding fortune is assigned to selectedFortune.
